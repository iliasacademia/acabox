# Long-tail no-code AI app builders and pro agentic-coding tools — research for the Acabox review

**Researcher group:** long-tail no-code builders (Base44, Emergent, Anything/Create.xyz, Figma Make, Canva Code, Hostinger Horizons, Glide/GlideOS, Airtable Omni, Microsoft Power Apps, Mocha, Databutton) + pro agentic tools for patterns only (Cursor, Windsurf/Devin Desktop, Devin, GitHub Copilot coding agent, Augment, Cline).
**As of:** 2026-09-30. Every URL below was read on 2026-09-30 unless a different date is given.
**Method and its limits:** the first passes used WebSearch (extended mode for 2026 changelogs and reviews). The session's search budget ran out after ~30 queries, so the rest was done by fetching official docs, changelogs and pricing pages by URL, plus named third-party reviews. Anything that comes only from a search summary or a third-party review and could not be confirmed on an official page is marked **unverified**. I did not audit Acabox code; "Acabox status" judgements use the repo's CLAUDE.md.

## 0. Selection

**Covered in depth (10):** Base44 (Wix), Emergent, Anything (formerly Create.xyz), Figma Make, Canva Code 2.0, Hostinger Horizons / Hostinger AI Builder, Glide + GlideOS, Airtable Omni, Microsoft Power Apps generative pages + app-builder skill (Copilot Studio adjacent), Mocha (shut down 2026-08-01 — kept because its post-mortem is the clearest public statement of what the credit model does to a consumer vibe-coding business). **Covered briefly:** Databutton (domain now redirects to an enterprise product, Riff).

**Skipped, and why:** Softgen (thin public footprint, undifferentiated from Emergent/Anything), Rork, a0.dev and Famous.ai (mobile-app-first; nothing a desktop data tool can borrow that Anything/Emergent don't already show), Tempo and Magic Patterns (UI/design generation for designers, not data apps), Softr AI (database front ends over Airtable/Sheets — the Airtable Omni entry covers that pattern better), Bubble AI (its AI is a scaffold generator over a visual-programming editor that is itself a technical skill; not a non-technical path). Create.xyz is covered under Anything (same company, renamed).

## 1. Headline findings

1. **Every consumer builder charges the user for the AI's own mistakes, and it is the single most common complaint on every platform.** Base44 Trustpilot 2.8/5 over 896 reviews, with "error/fix/error/fix loop" and "credits are non-refundable for AI behavior" quoted from support ([Trustpilot](https://www.trustpilot.com/review/base44.com)); Emergent 2.8/5 over 634 with "pay to fix a bug the platform created" ([Trustpilot](https://www.trustpilot.com/review/emergent.sh), [hackceleration](https://hackceleration.com/labs/review/emergent)); Hostinger "slot machine … diagnose, claim to fix, repeat until free credits were exhausted" ([tech.co](https://tech.co/ai/vibe-coding/hostinger-horizons-review), [vibeyourwebsite](https://vibeyourwebsite.com/hostinger-horizons-review/)); Mocha's shutdown post names "expensive unit economics from the AI tokens the product requires, and high support costs" ([Mocha, 2026-05-15](https://blog.getmocha.com/mocha-shutdown)). Acabox users pay Anthropic directly, so the same pain arrives as an API bill with no in-app explanation unless cost is visible and the fix loop is cheap.

2. **The two mechanics that most reduce wasted spend are deterministic and free of model calls:** (a) a cheaper "talk before building" mode — Base44 Discuss mode at ~0.3 message credits vs ~1 for Build, "nothing is built until you approve it" ([Base44 docs](https://docs.base44.com/Building-your-app/AI-chat-modes)); Mocha Discuss Mode; Cursor Plan mode; Cline Plan mode which "cannot modify any files"; and (b) a restore point before every change — Cursor checkpoints, Cline's shadow-git checkpoint after every tool use with three restore flavours, Windsurf's revert arrow and named checkpoints, Base44 version history (and a checkpoint created before any one-click security fix), Mocha "restore a previous version", Power Apps "roll back to previous versions with a single click". Glide's reviewer: "I wish there was an undo button" ([emergent.sh review of Glide, 2026-08-20](https://emergent.sh/learn/glide-review)) and GlideOS lists app version control as "in progress, Q3 2026" ([GlideOS recap, 2026-08-03](https://www.glideapps.com/blog/glideos-launch-recap)).

3. **Visual editing without the model is the third cost lever:** Base44 Edit mode manual changes are free ([Credits doc](https://docs.base44.com/Account-and-billing/Credits.md)); Figma Make point-and-edit with a properties panel, draw tool and annotations ([Figma Help](https://help.figma.com/hc/en-us/articles/31304412302231-Guide-to-Figma-Make)); Canva Code 2.0 "click into any section to retype text" though "element repositioning requires re-prompting" ([VentureBeat, 2026-07-14](https://venturebeat.com/technology/canva-launches-code-2-0-offering-ai-website-building-to-every-user-including-free-accounts)); Hostinger "edit every text and image element directly" (2026-08-14, [changelog](https://www.hostinger.com/changelog)).

4. **Cost is shown per prompt, after the fact, in the better products.** Base44: "More actions" under each prompt shows its cost, plus a per-app and per-branch usage page; Figma Make: "hover the AI credits icon beneath the prompt to see the actual cost" with no fixed price per prompt ([uichemy, 2026-09-11](https://uichemy.com/blog/figma-make-credits/)); GitHub session logs include token usage and duration; Augment/Devin per-user dashboards and budgets that pause access at a threshold.

5. **Autonomous QA is the 2026 trend among builders** — Emergent "testing agents click through the app, find broken flows, and fix them before you see the result" ([Emergent, 2026-09-16](https://emergent.sh/learn/best-ai-app-builders)); Anything Max "tests the app like a user and fixes issues until the objective is met" with "Visual QA with computer use agent" ([anything.com/pricing](https://www.anything.com/pricing)); Glide "autonomous testing" (unverified beyond a feed). It costs many model calls; the zero-cost cousin is capturing runtime errors on first load and offering a one-click fix.

6. **Only GlideOS treats data provenance as a product feature:** "inspect any calculation or UI element with natural-language explanations showing exactly how figures were derived" and "the system flags contradictions or missing data and asks the user for clarification rather than guessing silently" ([GlideOS recap](https://www.glideapps.com/blog/glideos-launch-recap)). For scientists that is the gap most worth owning.

7. **Plan approval with clickable clarifying questions is now standard in consumer builders:** Base44 plan mode "now conversational; AI reacts to answers and suggests missing considerations" (2026-09-10) with "clickable answer options" (2026-07-21) and design mockups included in questions; Hostinger "chat select: quick-select answers replacing typed responses" (2026-08-05); Cursor plan mode asks clarifying questions then "click to build the plan".

## 2. Platform inventories

Format per platform: what it does for a non-coder (the interaction) · errors · versioning · publishing · pricing/credits · praise and complaints · sources.

### 2.1 Base44 (Wix) — the most complete reference point

**What it does for a non-coder.** Chat on the left, live app preview on the right. Three chat modes ([AI chat modes](https://docs.base44.com/Building-your-app/AI-chat-modes)): **Build** ("type what you need, and the AI acts right away"), **Discuss** ("the AI answers you directly or proposes a change for you to review, and nothing is built until you approve it", ~0.3 credits/message), **Edit** (select elements in the preview and change them directly for free, or "Edit Element" to ask the AI). The changelog ([docs.base44.com/changelog/product](https://docs.base44.com/changelog/product)) shows the pace: in September 2026 alone — plan mode made conversational with the AI reacting to answers and suggesting what the brief left out (Sep 10); a slash menu listing workspace skills and integrations (Sep 14); the AI chat creating branches when main is protected (Sep 14); dictation auto-detecting the spoken language (Sep 16); "AI Visibility" tab (Sep 22); model picker personal to the user across apps (Sep 14); Claude Opus 5.5 and GPT 6 for in-app agents (Sep 22); Fable 5.1 for complex builds (Sep 2); Opus 5 used for initial planning turns (Sep 5). August: finished tool groups fold away while running ones stay open (Aug 30 — the exact layout Acabox shipped on 2026-09-22); build the same message on two models simultaneously and pick one (Aug 30); mid-turn messages join the running turn at the next step (Aug 17); queue follow-ups while the agent works (Jul 20); app testing screenshots appear in a chat gallery (Jul 12); AI chat asks approval before writing files to GitHub (Jul 12); Edit mode works on list items, table cells, buttons with live preview (Aug 9); comments pinned to app elements that stay anchored as the app changes (Aug 31).

**Errors.** "Resolve with AI" on errors; on paid plans "automatic AI fixes are free", on Free both auto-fixes and Resolve with AI consume credits; **failed generations are charged** ("the AI still has a lot to do in the background") ([Credits](https://docs.base44.com/Account-and-billing/Credits.md)). A Logs page with an "Errors only" toggle and per-user filtering ([Logs](https://docs.base44.com/Building-your-app/exploring-app-logs.md)); a security scan with one-click fixes that "creates a checkpoint before making the change" ([Security scan](https://docs.base44.com/Setting-up-your-app/running-a-security-scan.md)). Third-party guidance: restore a working snapshot before attempting a repair prompt, because "applying a repair prompt on top of fabricated code almost always produces a second layer of wrong logic" ([codeconductor](https://codeconductor.ai/blog/base44-errors/), unverified as official advice).

**Versioning.** Code/design "Version History" in the editor — Sep 14, 2026: "displays code changes with comparison to main or live versions"; Sep 7: "revert versions on branches; restore creates new commit on branch leaving main untouched". **Branches** (Aug 5–19): "behaves like full app copy with own preview, version history, and merge from chat"; the AI names the branch; genuine conflicts → the AI asks clarifying questions ([Branches](https://docs.base44.com/Building-your-app/working-with-branches.md)). **Data Backup & Restore** (Elite 7 days, Enterprise 30): browse snapshots newest first, filter by table and date, download a table as CSV from that moment, restore one table or the whole app; "editing pauses while a restore runs"; record IDs preserved; newly added records go to trash rather than being deleted; and the restore itself is undoable because the current state is saved first ([Backup & Restore](https://docs.base44.com/Enterprise/backup-and-restore.md)). Deleted apps restorable from Trash for 30 days (Aug 9).

**Publishing/sharing.** Publish from main; custom domains on Starter; DNS auto-setup (Aug 19); comments and @Base44 to hand a pinned comment (with its screenshot) to the AI ([Comments](https://docs.base44.com/Building-your-app/Commenting-on-your-app.md)); shared chat queue for collaborators on the same app (Sep 23); PWA/mobile and app-store packaging.

**Scheduled/background work.** Superagent "Workflows": scheduled or triggered, created by describing them, with an Activity tab of runs; "scheduled workflows that fail repeatedly are paused automatically, and you receive a notification"; runs cost message credits like chatting ([Workflows](https://docs.base44.com/superagents/setting-up-workflows.md)). Superagent "Goals" track long-running work across turns (Sep 15); Superagent turns extended to a 20-minute timeout (Sep 23); Superagent "remembers important facts and preferences across conversations automatically" with a one-step memory clear (Jul 19, Aug 2).

**Pricing/credits.** Two currencies: message credits (building) and integration credits (running). Free 25/100, Starter 100/2,000, Builder 250/10,000, Pro 500/20,000, Elite custom ([Billing](https://docs.base44.com/Account-and-billing/Billing-and-plans)). Third-party: $16–$160/month billed annually as of July 2026 ([jetadmin](https://www.jetadmin.io/blog/untitled-41/), unverified). Per-action integration costs are published (email ~1, image gen ~1, LLM call ~1 automatic / ~5 Gemini Flash / ~15 GPT-5.4, workflows ~0.1 per 10 steps). Usage is visible per prompt ("More actions" under the prompt), per app, per branch (Sep 21) and per day. At zero message credits you cannot send; at zero integration credits the app's actions fail with a generic error to end users.

**Praise / complaints.** Praise: a 67-year-old building a site "within two minutes"; a non-technical user shipping an app for contractors that saves "over 30 hours of work per week" ([Trustpilot](https://www.trustpilot.com/review/base44.com)). Complaints: the error/fix loop burning credits with support saying credits are "non-refundable for AI behavior"; "will not publish an updated version" after 148+ credits; a silent plan downgrade; "95% of monthly credits in the first week, primarily from fixing AI-introduced regressions" ([banani](https://www.banani.co/blog/base44-ai-review), [zite](https://www.zite.com/blog/base44-review)).

### 2.2 Emergent

**What it does for a non-coder.** Describe an app; "specialized agents split the work across the build" (interface, data/integrations) and "testing agents click through the app, find broken flows, and fix them before you see the result"; web (React/Next) and mobile (Expo) with live device preview; GitHub sync on Standard+ ("code is yours to open in VS Code, hand to a developer"); Emergent Auth, payments and hosting from the first build ([Emergent, 2026-09-16](https://emergent.sh/learn/best-ai-app-builders)). A Voice Mode to build hands-free ([superapp.dev](https://superapp.dev/blog/emergent-app-builder-review-2026-pricing-reviews-native-gap), unverified).

**Errors.** Reviewers saw the agent "identify the problem by analyzing backend logs and resolve the issue without human intervention" ([nocode.mba, 2026-05-19](https://www.nocode.mba/articles/ai-app-builder-emergent)), but "iterative fix cycles drain credits even when the AI introduces its own regressions" ([hackceleration, June 2026](https://hackceleration.com/labs/review/emergent)). Browser previews time out after 30 minutes.

**Versioning.** Nothing official found; Emergent's own feature article and homepage do not mention rollback or checkpoints. Users complain the platform "rolled back some of their changes without approval and charged thousands in credits again for retrieving those changes" (Trustpilot via search summary — unverified). Treat Emergent's versioning as **unknown/weak**.

**Publishing.** Deployed URL from the first build; mobile store submission "is on you".

**Pricing/credits.** Free 10 credits/month; Standard $20 (100 credits); Pro $200 (750 credits, 1M context, "Ultra thinking", custom agents); Business/Enterprise custom ([emergent.sh/pricing](https://emergent.sh/pricing)). Reviewer-estimated costs: landing page with form 10–20 credits, auth 25–40, Stripe 35–60, ~50/month to keep a deployment active; credits expire monthly; no tier between $20 and $200 ([hackceleration](https://hackceleration.com/labs/review/emergent), [blink.new, 2026-09-28](https://blink.new/blog/emergent-review)).

**Praise / complaints.** Trustpilot 2.8/5 (634): "$500+ without completing an app", "1.5 months of going back and forth" with support, €170 of credits expiring; praise for speed and for named support staff ([Trustpilot](https://www.trustpilot.com/review/emergent.sh)). "Fixing one bug can break a previously working feature"; "previously-fixed issues reappearing after platform updates".

### 2.3 Anything (formerly Create.xyz)

**What it does for a non-coder.** Prompt → full-stack web or native mobile app with Postgres (separate dev and production instances), auth, Stripe, file storage, image generation and "one-line access to current LLMs" without managing keys; 40+ integrations ([anything.com](https://www.anything.com/), [vibecoding.app, pricing read 2026-09-17](https://vibecoding.app/blog/anything-com-review)). The Max tier adds "Run multiple agents in parallel", "Visual QA with computer use agent", "Automated testing" and "Extended 1M context" ([anything.com/pricing](https://www.anything.com/pricing)). Mocha's users were migrated here one-click with $20 of credits when Mocha shut down ([Mocha, 2026-05-15](https://blog.getmocha.com/mocha-shutdown)).

**Errors.** "Automatic refactoring/error fixes"; Max agent "tests the app like a user and fixes issues until the objective is met". Reviewers: "long-running autonomous builds can still loop, credit burn on Max scales fast" (search summary, unverified).

**Versioning.** Create.xyz advertised version history (uibakery review, unverified); nothing found on current official pages — **unknown**.

**Publishing.** One-click deploy to custom domains (Pro+) and App Store via Expo/TestFlight; free tier projects are public only ([blink.new, 2026-09-28](https://blink.new/blog/anything-review)).

**Pricing/credits.** Free (20K credits, public projects); Pro $19/mo annual (20K credits, custom domains); Max $199/mo (220K credits, parallel agents, visual QA). Unused credits do not roll over (unverified).

**Complaints.** Public-only free tier; privacy behind the paywall; a 2026 App Store distribution dispute (unverified); "lack of agent-callable API/MCP surface".

### 2.4 Figma Make

**What it does for a non-coder.** Start from a prompt, paste a Figma design URL, or attach images/text; chat on the left, live interactive preview on the right; "you can run multiple prompts simultaneously without waiting for responses to finish". Three ways to edit without re-prompting the whole thing: **point-and-edit** (click an element, adjust properties in a Figma-Design-style panel), **draw tool** (mark up areas on the preview as instructions), **annotations** (labelled instructions pinned to elements) ([Figma Help — Guide to Figma Make](https://help.figma.com/hc/en-us/articles/31304412302231-Guide-to-Figma-Make)). Dated 2026 entries per release indexes (search summary; **partially verified** — the help guide confirms the mechanics, the dates were not re-fetched): Feb 20 featured connectors (Amplitude, Box, Dovetail, Granola…) and "connect Make to any remote MCP server"; Apr 2 Make kits and attachments ("prototypes start from real components, data, and constraints"); May 28 local code support; Jul 30 properties panel and annotations.

**Errors.** No "fix" button documented; reviewers report "occasional instability" and "needing to re-prompt" ([flowstep, 2026-02-28](https://flowstep.ai/blog/figma-make-pricing/)).

**Versioning.** "Access earlier versions of your app through the version history feature to experiment with different directions or restore previous iterations" (help guide).

**Publishing.** Share previews with granular permissions; publish to an org-only or public URL; custom domains; add a Supabase backend for login, saved state and secrets (help guide).

**Pricing/credits.** Make comes with every Full seat; Starter 500 credits shared, Professional 3,000 per Full seat, Organization 3,500, Enterprise 4,250; Dev/Collab/View seats 500 ([uichemy, 2026-09-11](https://uichemy.com/blog/figma-make-credits/)). No fixed price per prompt: ~30+ credits for a font change, 100+ to build an app shell; **"hover the AI credits icon beneath the prompt to see the actual cost"**; a disciplined six-page site ≈ 1,526 credits, i.e. half a Professional month, and doubling corrections exceeds the allowance. Add-on subscriptions (+5,000 credits $120/mo…) from March 11, 2026 and pay-as-you-go at $0.03/credit from Q2 2026 ([banani](https://www.banani.co/blog/figma-pricing-and-credits), [uxmagic](https://uxmagic.ai/blog/figma-pricing), unverified). Credits expire monthly, no rollover. Tips published to cut burn: use direct edits for styling (bypasses AI), one design per prompt, clear chat context when scope shifts, choose models deliberately.

**Praise / complaints.** "Quickly turns prompts into usable UI"; complaints of inconsistent, "template-like" output and refinement needed before production (flowstep).

### 2.5 Canva Code 2.0 (2026-07-14)

**What it does for a non-coder.** Describe an interactive thing (a calculator, quiz, site); Claude-powered generation inside Canva; then "click directly into generated elements to change text, drag and drop images from Canva's built-in library… update colors and fonts through a familiar toolbar"; one limitation: "element repositioning requires re-prompting". Import raw HTML "from ChatGPT, Claude, Lovable, or Bolt" into an editable design; real-time collaboration; publish publicly, password-protected or private link; embed in presentations/whiteboards ([VentureBeat, 2026-07-14](https://venturebeat.com/technology/canva-launches-code-2-0-offering-ai-website-building-to-every-user-including-free-accounts), [9to5Mac, 2026-07-14](https://9to5mac.com/2026/07/14/canva-code-2-0-adds-visual-editing-html-imports-and-real-time-collaboration/)). Stats: 75% less generation time, 30% faster prompt-to-publish (VentureBeat). Models: "a combination of proprietary and third-party models, including those from OpenAI and Anthropic".

**Errors / versioning.** Not documented in any source found.

**Pricing.** Available to all tiers including free accounts since 2.0 (VentureBeat); AI credits shared across Canva's AI features; an earlier review (2026-06-17, pre-2.0) said Free had no access and "heavy users may hit limits before the billing cycle resets" ([vibecoding.app](https://vibecoding.app/blog/canva-code-review)).

**Complaints.** "Locked into Canva's ecosystem — no code export or external hosting"; no backend/database/auth; "complex interactive applications exceed what prompt-based widget generation can handle".

### 2.6 Hostinger Horizons → Hostinger AI Builder

**What it does for a non-coder.** Chat-built sites/apps with hosting bundled. 2026 product updates ([Hostinger blog](https://www.hostinger.com/blog/product-updates-2026), [changelog](https://www.hostinger.com/changelog)): Feb — "new planning agent organizes tasks before execution", prompt guidance that turns targeted questions into complete prompts, built-in backend (DB, auth, storage, email); Apr — AI built in without setup; May 27 — publishing progress indicator with real-time percentage "and sound notification upon completion"; Jun — **Dynamic Credits** ("small tweaks cost less, while bigger builds use more"); Jul — recreate a website from a URL, convert PDFs/images/screenshots into working sites, direct live editing, **Version History** ("draft tracking and change recovery"); Aug 5 — chat select (quick-select answers instead of typing); Aug 14 — edit every text and image element directly; page generation understands the site's design and business logic. Horizons merged into "Hostinger AI Builder" with Horizons as "agentic mode" on 2026-08-18 (hostadvice via search summary — **unverified**; the changelog still says "Horizons" on Aug 14 and 26).

**Errors.** The weak spot. A non-technical reviewer spent 68 of 200 Hobbyist credits and abandoned a three-role scheduling app because the backend side "doesn't communicate" with the app: Horizons generated SQL the reviewer had to paste into Supabase 29 times ([allaboutcookies, 2026-01-21](https://allaboutcookies.org/hostinger-horizons-review)); others describe the "diagnose, claim to fix, repeat" loop until free credits were gone, and credits consumed even when the AI makes mistakes ([tech.co](https://tech.co/ai/vibe-coding/hostinger-horizons-review), [vibeyourwebsite](https://vibeyourwebsite.com/hostinger-horizons-review/)).

**Versioning.** Version history since July 2026 (official); multiple restorable versions in the WordPress AI builder (Aug 26).

**Publishing.** One click to Hostinger hosting with progress indicator; "deployment is the exact point where non-developers tend to give up" (tech.co, earlier version); must buy a hosting plan after the initial term.

**Praise.** "Screenshot-to-prototype speeds up initial build"; "click-to-isolate" to target a page element when editing (allaboutcookies).

### 2.7 Glide and GlideOS (beta 2026-06-04, public 2026-08-03)

**What it does for a non-coder.** Drop a multi-tab spreadsheet; "Sheet Sense" scans "formulas, comments, macros, pivot tables, charts, and conditional formatting" and the agent builds dashboards and lists; or browse App Store templates / "Help me get started" ([GlideOS recap](https://www.glideapps.com/blog/glideos-launch-recap)). Agent Mode (since 2025-07-02, new users first) builds from chat + reference photos + existing data ([community post](https://community.glideapps.com/t/agent-mode-a-new-ai-builder-experience-for-glide/82893)). Per the createwith.com feed (**unverified**): an "AI Agent Queue" to line up feature requests the agent processes sequentially; autonomous visual testing (announced 2026-05-27); an "Agents" settings page to connect your own Claude/ChatGPT subscription.

**Trust and errors.** "When spreadsheets contain inconsistencies or gaps, the system flags contradictions or missing data and asks the user for clarification rather than guessing silently"; "users can inspect any calculation or UI element with natural-language explanations showing exactly how figures were derived" (recap). Reviewer found a silent offline-sync failure with no warning ([emergent.sh Glide review, 2026-08-20](https://emergent.sh/learn/glide-review)).

**Versioning.** None for apps today — "I wish there was an undo button"; "app version control … in progress (Q3 2026): rollback for full applications, not just data"; roadmap also has "publishing approval workflows … a trusted approver to gate changes before they go live".

**Publishing.** One click, instant subdomain + QR code, private by default; publishing needs a paid plan.

**Pricing/credits.** Free; Basic $25 (100 credits, agent mode "light, medium, heavy"); Plus $50 (250); Pro $125 (500 + 50 per member); Enterprise with 30-day backups ([pricing](https://www.glideapps.com/pricing)). Light use consumed 42 "updates" in 12 days (reviewer). G2 4.7 vs Trustpilot <2.4 — "the people building the apps are happier than the people living with them".

### 2.8 Airtable Omni

**What it does for a non-coder.** Describe the app; "you chat with Omni on the left side while your app builds on the right"; creates tables, interfaces, automations and field agents; "everything Omni creates is fully editable using Airtable's drag-and-drop visual tools" ([Airtable AI](https://www.airtable.com/platform/ai)). Reviewer: "almost like having an Airtable consultant do the initial setup for you" ([nocode.mba, 2026-09-23](https://www.nocode.mba/articles/airtable-omni-review)). Cobuilder and a Claude connector for analysis (search summary — unverified).

**Errors.** No auto-fix; "treat it as a fast first draft"; it did not create all requested automations; cannot pull from external APIs; struggles with unsupported layouts and complex calculations.

**Versioning.** Not addressed anywhere found — unknown (Airtable has record revision history generally, not covered here).

**Pricing/credits.** "Building and iterating apps with Omni is complimentary. However, analysis questions about your data cost 10 credits per response"; requires Airtable AI enabled with credits; available across plan types.

### 2.9 Microsoft Power Apps (generative pages, app-builder skill) and Copilot Studio

**What it does for a non-coder.** "Describe the app you want, optionally upload a whiteboard sketch, choose your Dataverse tables", then "collaborate with agents to shape user stories, requirements, processes, data, and solution architecture" (plan designer), preview, "view the React code behind your app", iterate by stating changes, and "roll back to previous versions with a single click" ([Introducing the new Power Apps, 2025-07-21](https://www.microsoft.com/en-us/power-platform/blog/power-apps/introducing-the-new-power-apps-generative-power-meets-enterprise-grade-trust/)). 2026: external coding tools (GitHub Copilot CLI) can build generative pages, GA April 2026; pages accept input context, May 2026 (search summary — partially verified); September 2026 — app-builder skill GA to "vibe code entire model-driven apps" using GitHub Copilot CLI or Claude Code, generative pages embedded in forms, connector support in preview, canvas authoring agent plugin GA ([September 2026 update](https://www.microsoft.com/en-us/power-platform/blog/power-apps/whats-new-in-power-platform-september-2026-feature-update/)).

**Governance.** Entra ID auth, RBAC, DLP policies, ALM pipelines, auditing — the trust story is the product.

**Pricing.** Not stated in the sources (licensing + Copilot credits elsewhere) — unknown.

### 2.10 Mocha (shut down 2026-08-01) — the post-mortem

**What it did.** Full-stack apps with DB, auth, email, analytics and Stripe built in so non-technical users never saw Supabase/Resend ([GlobeNewswire, 2026-02-18](https://www.globenewswire.com/news-release/2026/02/18/3240316/0/en/AI-Web-App-Builder-Mocha-Launches-New-Email-and-Analytics-Tools-New-AI-Agent-To-Help-Small-Business-Users-Build-and-Publish-Projects-in-Hours.html)). MAX agent "powered by Claude's most capable model" (2026-01-08); **Discuss Mode** upgraded with "live app investigation" (2026-01-26) ([blog](https://blog.getmocha.com/)).

**Errors / versioning.** "Fix with AI" button on errors; Discuss Mode to describe issues; error logs and console; "Restore a previous version" when Mocha misinterprets a request ([FAQ](https://docs.getmocha.com/getting-started/faq)).

**Pricing.** Starter 20 credits; Bronze $20 (1,500); Silver $50 (4,500); Gold $200 (20,000); simple tasks a few credits, larger 15–50, rare >100; subscription credits accumulate up to 2× monthly; purchased credits never expire ([nocode.mba](https://www.nocode.mba/articles/mocha-pricing), FAQ).

## 4. Cross-cutting patterns

1. **Cost legibility beats cost reduction in reviews.** Platforms with opaque per-prompt pricing get "slot machine" reviews; the ones with per-prompt cost on hover (Figma Make) or under the prompt (Base44) still get complaints, but about policy ("non-refundable for AI behaviour"), not confusion.
2. **Make the second attempt cheap or free.** Base44 (paid plans) makes automatic fixes free and Discuss mode ~0.3 credits; Devin doesn't charge while waiting; Hostinger's dynamic credits make small tweaks cheaper. All three change the user's willingness to iterate.
3. **A restore point before every change is table stakes in pro tools and arriving in consumer tools.** Three restore flavours (files / conversation / both) is the mature form; "irreversible revert" (Windsurf) is the immature form; Base44's undoable restore of a restore is the best data version.
4. **Separate "building" from "running" costs** (Base44 message vs integration credits; Omni free to build, 10 credits to ask). Users accept paying to run; they resent paying to rebuild.
5. **Point at the thing.** Point-and-edit, draw tool, annotations, click-to-isolate, pinned comments with a screenshot sent to the AI — every builder has converged on "select an element, then talk". Manual edits of text/colour should not need the model at all.
6. **Plan, with questions that have buttons.** Clickable clarifying options and mockups before the build; conversational plan mode that "suggests missing considerations".
7. **Progress is a live, foldable log plus a status chip** (working / blocked / done), with OS notifications when attention is needed and a sound on completion.
8. **Honesty over guessing** is a trust feature only GlideOS sells: flag contradictions, ask, and let the user inspect how any figure was derived.
9. **Autonomous QA before showing the result** is the 2026 frontier (Emergent, Anything Max, Glide) — expensive, but it is what turns "vibe" into "I can hand this to a colleague".
10. **Memory should announce itself and be vetoable** (Augment, Devin Knowledge suggestions, Base44 one-step memory clear).
11. **Time-boxed sessions and auto-pause of failing automations** keep unattended spend bounded (Base44 workflows pause after repeated failures and notify; Devin sessions sleep; Copilot 59-minute cap; Superagent 20-minute turn cap).
12. **The credit-funded consumer builder is a fragile business** (Mocha's shutdown; Emergent/Base44 2.8/5). Acabox's bring-your-own-key model avoids the margin problem but inherits the user-facing one: unexplained spend.
